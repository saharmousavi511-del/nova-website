# نووا (NOVA) — وب‌سایت گروه مشاوره کنکور

وب‌سایت فارسیِ راست‌به‌چپ گروه مشاوره کنکور **نووا**؛ با الهام از تجربه سایت‌های مشاوره‌ای موفق کنکور و با تمرکز بر سه چیز:

1. **معرفی خدمات و طرح‌های مشاوره** (طرح نُوا، سوپرنُوا، کهکشان و امتحان نهایی)
2. **فرم ثبت‌نام چهارمرحله‌ای** با اعتبارسنجی فارسی، ذخیره خودکار پیش‌نویس و کد رهگیری
3. **آزمون آنلاین** با دفترچه‌های زمان‌دار، پاسخ‌نامه، نمره منفیِ رسمی کنکور و کارنامه درس‌به‌درس با پاسخ تشریحی

به این‌ها اضافه شده: **تست انتخاب رشته «نوا‌مچ»**، **بلاگ آموزشی**، **پروفایل مشاوران**، **کارنامه رتبه‌برترها** و **داشبورد داخلی** برای دیدن فرم‌ها و کارنامه‌های ثبت‌شده.

## شروع سریع

```bash
npm install        # نصب وابستگی‌ها
npm run dev        # سرور توسعه روی http://localhost:5173
npm run build      # ساخت نسخه تولید در dist/
npm run preview    # پیش‌نمایش نسخه تولید
npm run typecheck  # بررسی انواع تایپ‌اسکریپت
npm run test:logic # آزمون منطق (بانک سؤال، نمره‌دهی، تقویم، اعتبارسنجی)
```

نیازمندی: Node.js نسخه ۲۰ به بالا.

## جریان داده فرم‌ها و آزمون‌ها

همه داده‌ها به‌صورت پیش‌فرض در **localStorage همان مرورگر** ذخیره می‌شوند (کلیدهای با پیشوند `nova:`) و در صفحه `/panel` قابل مشاهده، ویرایش وضعیت، حذف و خروجی CSV هستند. این یعنی سایت بدون هیچ بک‌اندی کامل کار می‌کند.

### اتصال به بک‌اند / وب‌هوک (اختیاری)

اگر بخواهید فرم‌ها و کارنامه‌ها به یک سرور مرکزی هم ارسال شوند، کافی است متغیر محیطی زیر را تنظیم کنید:

```bash
# .env
VITE_SUBMISSIONS_URL=https://script.google.com/macros/s/XXXXXXXX/exec
```

سایت به آن آدرس یک درخواست `POST` با بدنه JSON می‌فرستد:

```json
{ "kind": "registration", "payload": { "...": "کل فرم ثبت‌نام" }, "receivedAt": "2026-09-22T..." }
```

مقدار `kind` یکی از `registration` یا `exam-result` است.

#### نمونه دریافت‌کننده Google Apps Script

```js
function doPost(e) {
  const sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  const body = JSON.parse(e.postData.contents);
  const p = body.payload || {};
  sheet.appendRow([new Date(), body.kind, JSON.stringify(p)]);
  return ContentService.createTextOutput(JSON.stringify({ ok: true }))
    .setMimeType(ContentService.MimeType.JSON);
}
```

## موتور آزمون آنلاین

- **بانک سؤال:** `src/data/questions.ts` — ۱۳۸ سؤال چهارگزینه‌ای در ۱۷ درس با پاسخ تشریحی.
- **دفترچه‌ها:** `src/data/exams.ts` — ۸ آزمون (تعیین سطح تجربی/ریاضی/انسانی، شبیه‌ساز نهایی، استعداد تحصیلی، آزمون سریع، جامع ۱۴۰۶، سبک مطالعه). هر آزمون چند «دفترچه/مرحله» با سهمیه سؤال از هر درس و زمان مستقل دارد.
- **برگه داوطلب‌محور:** ترتیب و گزینش سؤال‌ها از روی «کد داوطلبی + شماره دفعه» تولید می‌شود (`buildPaper`)؛ پس هر داوطلب برگه متفاوت می‌بیند، در آزمون دوباره سؤال‌ها تکرار نمی‌شوند و برگه هر کد قابل بازتولید است (کارنامه همان برگه را دوباره می‌سازد).
- **نمره‌دهی:** دقیقاً مثل کنکور سراسری — هر ۳ پاسخ غلط یک پاسخ درست را حذف می‌کند؛ کارنامه شامل درصد درس‌به‌درس، درست/غلط/نزده، زمان هر مرحله، تراز تقریبی (۳۰۰ تا ۱۰۰۰۰) و سطح عملکرد است.
- **تجربه آزمون:** تایمر هر دفترچه جداست و با پایان زمان همان مرحله خودکار ثبت می‌شود؛ پاسخ‌نامه پرشی، نشان‌دار کردن سؤال، میان‌برهای کیبورد (۱ تا ۴ برای گزینه، ← و → برای جابه‌جایی، F برای نشان‌دار کردن) و گفتگوی تأیید «ثبت و مرحله بعد» وجود دارد.
- **کد داوطلبی:** اگر کد رهگیریِ فرم ثبت‌نام را وارد کنید، پرونده داوطلب شناسایی می‌شود؛ وگرنه هر کد دلخواهی پذیرفته است (حالت میهمان).

منطق خالص آزمون و تقویم با `npm run test:logic` بررسی می‌شود (تعداد سؤال هر دفترچه، عدم تکرار، نمره‌دهی مرزی، تبدیل میلادی↔جلالی، اعتبارسنجی موبایل/کد ملی).

## ویرایش محتوا

همه محتوا در فایل‌های داده جداست تا بدون دست‌زدن به کامپوننت‌ها قابل ویرایش باشد:

| فایل | محتوا |
| --- | --- |
| `src/data/site.ts` | نام، شعار، تلفن/ایمانی/آدرس، شبکه‌های اجتماعی و **تاریخ کنکور برای شمارش معکوس** |
| `src/data/services.ts` | خدمات، ویژگی‌ها، طرح‌ها و قیمت‌ها، مسیر همکاری |
| `src/data/consultants.ts` | مشاوران (نام، رشته، دانشگاه، رتبه، ظرفیت، بیو) |
| `src/data/toppers.ts` | رتبه‌برترها و کارنامه‌های نمونه |
| `src/data/testimonials.ts` | نظرات دانش‌آموزان و خانواده‌ها |
| `src/data/posts.ts` | مطالب بلاگ با بلوک‌های متنی (پاراگراف، تیتر، فهرست، نقل‌قول، نکته) |
| `src/data/faqs.ts` | پرسش‌های متداول |
| `src/data/exams.ts` | دفترچه‌ها، سهمیه سؤال و زمان‌ها |
| `src/data/questions.ts` | بانک سؤال و پاسخ تشریحی |

## طراحی و برند

- **تم:** «کهکشان کنکور» — پس‌زمینه فضای عمیق `#05070f` با هاله‌های سحابی، آسمان پرستاره انیمیشنی (canvas)، کارت‌های شیشه‌ای و رنگ تأکیدی کهربایی/مرجانی/بنفش.
- **فونت:** وزیرمتن (Vazirmatn) به‌صورت **خودمیزبان** از `public/fonts` (فونت متغیر + وزن‌های ثابت)؛ بدون وابستگی به CDN.
- **اعداد و تاریخ:** همه اعداد فارسی و تاریخ‌ها جلالی هستند (`src/lib/fa.ts` شامل تبدیل دقیق میلادی↔جلالی).
- **راست‌به‌چپ:** `dir="rtl"` روی `<html>` و استفاده از کلاس‌های منطقی Tailwind (`ms/me/ps/pe/start/end`).
- **دسترس‌پذیری:** برچسب‌های ARIA روی فرم‌ها/گفتگوها، فوکوس قابل دیدن، احترام به `prefers-reduced-motion` و سبک چاپ جدا برای کارنامه (`@media print`).

توکن‌های رنگ، شعاع و انیمیشن در `@theme` داخل `src/index.css` تعریف شده‌اند.

## انتشار

- **Netlify:** خروجی `dist` را منتشر کنید؛ فایل `public/_redirects` همه مسیرها را به `index.html` می‌فرستد (SPA).
- **Vercel / هاست استاتیک:** همین خروجی کافی است؛ در صورت نیاز یک rewrite اضافه کنید: `/* → /index.html`.
- **GitHub Pages:** مسیر پایه را با `base` در `vite.config.ts` تنظیم و یک `404.html` کپی از `index.html` اضافه کنید.

## یادداشت‌های فنی

- React 19 + TypeScript + Vite 6 + Tailwind CSS v4 (پیکربندی CSS-first).
- مسیریابی با react-router v7 و بارگذاری تنبل صفحات داخلی برای سبک‌ماندن باندل اولیه.
- آیکون‌ها از lucide-react و آیکون‌های برند (تلگرام/واتساپ/آپارات) به‌صورت SVG داخلی.
- هیچ ردیاب (tracker) یا فونت CDN خارجی استفاده نشده است.
